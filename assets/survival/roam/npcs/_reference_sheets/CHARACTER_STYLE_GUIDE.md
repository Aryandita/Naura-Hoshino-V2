# 🎨 Roam & Date System, NPC Character Style Guide

> **Untuk Agen AI & Developer:** Dokumen ini adalah pedoman visual wajib untuk semua pembuatan atau regenerasi aset karakter NPC sistem Roam & Date. Selalu gunakan reference sheet yang tersedia di folder ini sebagai acuan utama sebelum membuat gambar baru.

---

## 📐 Standar Umum Semua Karakter

| Parameter | Nilai |
|---|---|
| **Art Style** | Anime visual novel sprite (flat cel-shading) |
| **Background** | Transparan / Putih bersih (untuk portrait) |
| **Aspect Ratio Portrait** | 1:1 (1024x1024px) |
| **Aspect Ratio Ref Sheet** | 3:2 (1280x853px) |
| **Shading** | Flat cel-shading, max 2 shadow tones |
| **Outline** | Clean black/dark anime line art |
| **Framing** | Waist-up untuk portrait emosi (NPC sprite) |
| **Views di Ref Sheet** | Front, 3/4, Back |

**Penting:** Semua karakter harus konsisten secara visual antara emotion portrait satu dengan lainnya. Gunakan file `*_reference.png` di folder `assets/survival/roam/npcs/_reference_sheets/` sebagai anchor visual utama.

**File Referensi:** `_reference_sheets/ningsih_reference.png`

|---|---|

## 🖼️ Panduan Prompt untuk Agen AI

Saat membuat ulang atau menambah emotion portrait baru, gunakan template prompt berikut:

```
"Anime visual novel character portrait of [NAMA], waist-up, transparent background.
Based on canonical reference: [DESKRIPSI SINGKAT KARAKTER].
[OUTFIT SPESIFIK DARI TABEL DI ATAS].
Emotion: [NAMA_EMOSI] - [DESKRIPSI EKSPRESI].
Style: flat cel-shading anime, clean black outline, soft lighting.
Colors exactly match: Hair [HEX], Skin [HEX], Outfit [HEX].
No background, character centered, 1:1 aspect ratio."
```

**Selalu sertakan ImagePaths dengan file referensi dari folder _reference_sheets/ untuk menjaga konsistensi.**
