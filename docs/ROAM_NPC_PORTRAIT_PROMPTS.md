## 💡 TIPS GENERASI

1. **Batch processing:** Generate 5-10 gambar per sesi untuk efisiensi

3. **Priority order:** Romansa NPCs dulu (date system), lalu teman populer
4. **Fallback:** Jika emosi tertentu gagal, gunakan neutral sebagai placeholder
5. **File naming:** Selalu gunakan format `{npc_id}_{emotion}.png` lowercase
6. **Folder structure:** Buat folder per NPC sebelum generate
